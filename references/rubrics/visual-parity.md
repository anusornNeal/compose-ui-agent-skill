# Visual Parity Rubric

Score each state from `1` to `5`.

- `5`: Layout, spacing, hierarchy, and state details match the reference closely with no meaningful visual defects.
- `4`: Minor visual differences exist, but the screen reads the same and no issue is likely to confuse users.
- `3`: Noticeable mismatches exist in spacing, alignment, proportion, or emphasis, but the screen remains usable.
- `2`: Major mismatches change the perceived structure, hierarchy, or state communication.
- `1`: The implementation does not reflect the intended screen or state.

Reject the result if repeated issues remain in spacing, alignment, component sizing, or state-specific content.
