# UX Quality Rubric

Score each state from `1` to `5`.

- `5`: The screen is clear, accessible, consistent, and easy to act on.
- `4`: The screen is solid, with only minor clarity or polish issues.
- `3`: The screen is understandable, but some content, affordances, or hierarchy feel weak.
- `2`: The screen has clear usability or accessibility problems.
- `1`: The screen is confusing, misleading, or difficult to use.

Check:

- Text clarity and hierarchy
- Reachable affordances
- Accessible touch targets and semantics
- Error, empty, and loading state clarity
- Consistency with existing product behavior
