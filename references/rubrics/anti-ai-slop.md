# Anti-AI-Slop Rubric

Fail the design or implementation if any of these patterns appear:

- Generic Material 3 filler that ignores the project visual language
- New visual motifs that do not exist in the product without explicit approval
- Decorative gradients, badges, cards, or shapes added without product intent
- Placeholder copy, repeated labels, or invented product language
- Inconsistent spacing rhythm or arbitrary token choices
- Inline typography or color values that bypass established conventions
- Layouts that look polished in isolation but ignore state realism, density, or actual content constraints

Pass only when the screen feels native to the existing product and its real states.
