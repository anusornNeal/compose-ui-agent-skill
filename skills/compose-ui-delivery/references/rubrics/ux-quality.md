# UX Quality Rubric

Score each rendered state from `1` to `5`.

- `5`: The task, hierarchy, content, accessibility, responsive behavior, and recovery path are clear on the selected platform.
- `4`: The experience is strong with only minor clarity, density, focus, or polish issues.
- `3`: The task is possible, but affordances, state handling, focus order, resizing, or responsiveness is weak.
- `2`: Important actions, content, errors, recovery, or platform input behavior are confusing.
- `1`: The implementation obstructs or misrepresents the task.

Check real content, long text, loading/empty/error states, semantics, touch or pointer reachability, keyboard and focus behavior, scrolling, resizing, and consistency with existing product behavior.
