# Anti-AI-Slop Rubric

Fail the implementation when any unsupported pattern appears:

- Generic Material, dashboard, or landing-page filler that ignores the product language
- Decorative gradients, glass surfaces, floating cards, pills, badges, blobs, or illustrations without task value
- Placeholder or invented copy, fake metrics, repeated labels, or unrealistic content
- Arbitrary spacing, corner radius, color, typography, or animation outside project conventions
- A polished default state that ignores loading, empty, error, disabled, focus, hover, resize, or small-screen behavior
- Platform behavior copied from Android onto web or desktop without adapting input, responsiveness, and system integration

Pass only when the rendered result feels native to the project, selected platform, real content, and real states.
