# Visual Parity Rubric

Score each referenced state from `1` to `5`.

- `5`: Layout, spacing, hierarchy, typography, component sizing, and state details match closely with no meaningful defect.
- `4`: Minor differences exist, but the screen reads and behaves the same.
- `3`: Noticeable differences exist in alignment, proportion, emphasis, wrapping, or state detail, while the task remains usable.
- `2`: Major differences change the perceived structure, hierarchy, or state communication.
- `1`: The implementation does not represent the referenced screen or state.

Reject repeated spacing, alignment, sizing, clipping, responsive, or state-content defects. Pixel metrics support review but do not replace human inspection or platform functional checks.
