# UX Quality Rubric

Score each proposed state from `1` to `5`.

- `5`: Task priority, hierarchy, content, accessibility, platform behavior, and recovery paths are immediately clear.
- `4`: The flow is strong with minor clarity, density, or polish issues.
- `3`: The user can complete the task, but hierarchy, affordance, state handling, or responsiveness is weak.
- `2`: Important actions, content, focus order, resizing, errors, or recovery are confusing.
- `1`: The design obstructs or misrepresents the user task.

Check real content, long text, empty/loading/error states, focus and keyboard behavior, touch or pointer reachability, responsive reflow, and consistency with existing product behavior.
