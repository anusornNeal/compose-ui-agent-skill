# Anti-AI-Slop Rubric

Fail the direction when any pattern appears without product evidence:

- Generic Material or dashboard filler that ignores the product language
- Decorative gradients, glass surfaces, floating cards, pills, badges, blobs, or illustrations
- Oversized marketing hierarchy inside a task-focused application screen
- Placeholder copy, invented claims, repeated labels, or fake metrics
- Arbitrary spacing, corner radius, color, or type choices outside project tokens
- Excessive empty space that hides realistic content density
- A polished default state with missing loading, empty, error, disabled, focus, hover, resize, or small-screen behavior

Pass only when the direction feels native to the product, platform, real content, and real states.
